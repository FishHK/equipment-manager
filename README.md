# 備品管理アプリ

HTML・CSS・JavaScriptのみ。外部ライブラリやビルドは不要です。

## 起動

`index.html` を同じブラウザで開いてください。編集後は再読み込みします。

## 操作

- 貸出：社員を選択、または名前を入力し、倉庫の物品を選んで「借りる」。未登録の名前は社員として追加します。
- 返却：社員を選ぶと、その人が借りている物品だけ表示。「返す」で返却日を記録します。
- 物品一覧：倉庫／貸出中、借りている人、貸出日を確認します。
- 記録：貸出日と返却日を含む履歴を確認します。

初回は社員・物品各40件を作成します。社員・物品・貸出記録のIDは内部の連番で、画面には表示しません。同じ製品名・モデル番号の物品は表示名に (1)、(2) を付けます。

## 保存

データはブラウザのlocalStorageに保存します。GitHubには業務データを送りません。ブラウザのデータを削除すると記録も消えます。別のブラウザやPCとは共有されません。ファイルの移動やブラウザによって保存先が変わる場合があるため、同じ場所・ブラウザで利用してください。

## ファイル

- `index.html`：4つの画面
- `style.css`：見た目
- `script.js`：社員・物品・履歴の管理

このフォルダだけを1つのGitリポジトリとして管理します。
