# 備品管理アプリ

HTML・CSS・JavaScriptのみ。外部ライブラリやビルドは不要です。

## 起動

`index.html` を同じブラウザで開いてください。編集後は再読み込みします。

## 操作

- 貸出：社員を選択、または名前を入力し、倉庫の物品を選んで「借りる」。未登録の名前は社員として追加します。
- 返却：社員を選ぶと、その人が借りている物品だけ表示。「返す」で返却日を記録します。
- 物品一覧：倉庫／貸出中、借りている人、貸出日を確認します。
- 記録：貸出日と返却日を含む履歴を確認します。

初回は社員・物品各40件を作成します。社員・物品・貸出記録のIDは内部の連番で、画面には表示しません。同じ製品名・モデル番号の物品は表示名に (1)、(2) を付けます。

## 保存

データはブラウザのlocalStorageに保存します。GitHubには業務データを送りません。ブラウザのデータを削除すると記録も消えます。別のブラウザやPCとは共有されません。ファイルの移動やブラウザによって保存先が変わる場合があるため、同じ場所・ブラウザで利用してください。

## ファイル

- `index.html`：4つの画面
- `style.css`：見た目
- `script.js`：社員・物品・履歴の管理

このフォルダだけを1つのGitリポジトリとして管理します。

## 予約・返却期限・物品登録

- 予約：社員、物品、予約日、返却予定日を選んで予約します。物品ごとに有効な予約は1件です。貸出中の物品は、返却予定日の翌日以降に予約できます。
- 予約から貸出：本日の予約のみ表示。社員から選ぶと物品を絞り、物品から選ぶと予約者を絞って自動入力します。「選択解除」で全件へ戻ります。予約時の返却予定日を初期入力します。
- 通常貸出：返却予定日が必須です。予約当日は予約者のみ貸出可能。将来の予約がある場合は予約日前までの返却が必要です。
- 期限超過：返却予定日の翌日から、未返却の社員を社員一覧で赤く表示し「返却期限超過あり」を付けます。返却すると解除します。
- 物品登録：製品名だけで登録可能。モデル番号は任意です。
- 予約日を過ぎて未貸出の予約は期限切れとなり、予約制限を解除します。履歴は残ります。

既存の保存データは引き継ぎます。追加前の貸出は返却予定日がないため「未設定」と表示し、期限超過の判定対象にはしません。

## テストデータ

再読み込み時にテスト社員15件・物品27件・貸出履歴16件・予約10件を一度だけ追加します。既存データは保持します。詳細は [TEST-DATA.md](TEST-DATA.md) を参照してください。

貸出ページの返却予定日は今日が初期値です。
